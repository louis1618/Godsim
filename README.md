# Godsim

**작은 세계, 신의 손끝.** 멀리서는 살아 움직이는 2D 세계지도, 가까이서는 생생한 3D 오픈월드인 신(神) 샌드박스 시뮬레이터입니다.
Three.js + TypeScript + Rapier로 만들었고, 모든 모델·아이콘·사운드는 코드로 절차적으로 생성됩니다(외부 에셋 없음).

## 실행

```bash
npm install
```

```bash
npm run dev
```

브라우저에서 `http://localhost:5173` 을 엽니다. 배포용 빌드는 `npm run build` (결과물: `dist/`).

## 플레이

- **타이틀 → 새 세계**: 크기·지형·생명·씨앗을 고르면 배경의 세계가 바다에서 솟아오르며 바로 미리보기됩니다. **창조**를 누르면 카메라가 3D 디오라마에서 지도 시점으로 내려앉으며 게임이 시작됩니다.
- **카메라**: 마우스 휠 = 확대/축소(커서 기준). 확대할수록 탑뷰 지도가 기울어지며 3D 세계로 바뀝니다. 우클릭 드래그 또는 WASD = 이동, 휠 클릭 드래그 또는 Q/E = 회전, 오른쪽 고도계 아이콘 = 지도/산/사람 높이로 이동.
- **신의 능력**: 하단 도구 막대의 7개 분류(대지·생명·문명·자연·재난·관찰·설정). 좌클릭으로 사용, 브러시는 누른 채 드래그. `[` `]` 또는 Ctrl+휠 = 브러시 크기, Esc = 선택 해제/메뉴, Space = 일시정지, `,` `.` = 시간 배속.
- **단축키**: 1–6 지형 도구, L 번개, B 폭탄, M 운석, H 신의 손, I 살펴보기, F 따라가기.
- **관찰**: 주민이나 마을을 클릭하면 정보 카드가 열리고, *따라가기*로 그 주민의 3D 생활을 가까이서 볼 수 있습니다. 왼쪽 사건 알림을 누르면 그 장소로 날아갑니다.

## 세계가 스스로 하는 일

- 주민은 채집·벌목·채석·농사·사냥·건설을 하고, 아이가 태어나 자라며, 마을은 집·농장·창고·풍차·탑·신전을 지어 성장하고 개척민을 보내 새 마을을 세웁니다.
- 왕국은 왕위 계승, 호감도에 따른 동맹·전쟁·평화, 원정군 집결·진군·공성·점령, 멀리 떨어진 마을의 반란을 겪습니다. 전투에서 살아남은 주민은 영웅이 됩니다.
- 생태계: 나무는 자라고 퍼지며, 동물은 풀을 뜯고 번식하고 늑대·곰은 사냥합니다. 계절(단풍·눈), 비구름, 번지는 불, 무작위 재해(토네이도·운석·지진·역병)가 일어납니다.

## 구조

| 경로 | 역할 |
| --- | --- |
| `src/sim/` | 렌더링과 무관한 순수 시뮬레이션(세계 생성, 주민 AI, 마을·왕국, 자연, 재해, 신의 능력, 저장). 다른 엔진으로 옮기기 쉽도록 타입 배열과 평범한 객체만 사용 |
| `src/render/` | Three.js 렌더링: 2D↔3D 카메라 리그, 지형/물 셰이더, 인스턴싱된 식생·건물·생명체, 이펙트, 아이콘 포지, 후처리 |
| `src/render/models/` | 절차적 모델링 키트와 모든 3D 모델(종족별 건축, 생명체, 식물) |
| `src/physics/` | Rapier 물리(날아가는 주민, 던지기, 파편) |
| `src/audio/` | WebAudio로 합성하는 효과음·환경음·생성 음악 |
| `src/ui/` | Preact UI(타이틀, 세계 생성, HUD, 도구 막대, 패널, 지도 라벨) |
| `tools/simtest.ts` | 헤드리스 시뮬레이션 테스트: `npx tsx tools/simtest.ts <seed> <years> <tribes> <size>` |
