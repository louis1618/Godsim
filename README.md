# Godsim

**작은 세계, 신의 손끝.** 멀리서는 살아 움직이는 2D 세계지도, 가까이서는 생생한 3D 오픈월드인 신(神) 샌드박스 시뮬레이터입니다.
Three.js + TypeScript + Rapier로 만들었고, 모든 모델·아이콘·사운드는 코드로 절차적으로 생성됩니다(외부 에셋 없음).

## 실행

```bash
npm install
```

```bash
npm run dev
```

브라우저에서 `http://localhost:5173` 을 엽니다. 배포용 빌드는 `npm run build` (결과물: `dist/`).

## 플레이

- **타이틀 → 새 세계**: 크기·지형·생명·씨앗을 고르면 배경의 세계가 바다에서 솟아오르며 바로 미리보기됩니다. **창조**를 누르면 카메라가 3D 디오라마에서 지도 시점으로 내려앉으며 게임이 시작됩니다.
- **카메라**: 마우스 휠 = 확대/축소(커서 기준). 확대할수록 탑뷰 지도가 기울어지며 3D 세계로 바뀝니다. 우클릭 드래그 또는 WASD = 이동, 휠 클릭 드래그 또는 Q/E = 회전, 오른쪽 고도계 아이콘 = 지도/산/사람 높이로 이동.
- **신의 능력**: 하단 도구 막대의 8개 분류(대지·생명·문명·자연·재난·무기·관찰·설정). 아무 탭도 고르지 않으면 *홈 메뉴*(살펴보기·신의 손·따라가기·최근 사용·매뉴얼·통계 등)가 보입니다. 좌클릭으로 사용, 브러시는 누른 채 드래그. 선택한 능력을 다시 누르거나 Esc = 선택 해제(자유 이동). 도구 막대는 마우스 드래그·휠로 가로 스크롤됩니다.
- **브러시**: 도구 막대 왼쪽 버튼 → 원·사각·마름모·스프레이 모양, 크기, *수량*(소환·재난을 범위 안에 여러 번) 설정. 슬라이더를 움직이면 미리보기와 월드의 브러시 윤곽이 즉시 바뀝니다. `[` `]` = 크기, Space = 일시정지, `,` `.` = 시간 배속.
- **단축키**: 1–6 지형 도구, L 번개, B 폭탄, M 운석, N 핵, H 신의 손, I 살펴보기, F 따라가기, F1 매뉴얼.
- **매뉴얼**: 처음 방문하면 그림 매뉴얼을 볼지 묻습니다. 조작·먹이사슬 피라미드(시뮬레이션의 먹이 표에서 생성)·시대별 건물/직업·연쇄 반응·팁.
- **관찰**: 주민이나 마을을 클릭하면 정보 카드가 열리고, *따라가기*로 그 주민의 3D 생활을 가까이서 볼 수 있습니다. 왼쪽 사건 알림을 누르면 그 장소로 날아갑니다.

## 세계가 스스로 하는 일

- 주민은 채집·벌목·채석·농사·사냥·건설을 하고, 아이가 태어나 자라며, 마을은 집·농장·창고·풍차·탑·신전을 지어 성장하고 개척민을 보내 새 마을을 세웁니다.
- 왕국은 왕위 계승, 호감도에 따른 동맹·전쟁·평화, 원정군 집결·진군·공성·점령, 멀리 떨어진 마을의 반란을 겪습니다. 전투에서 살아남은 주민은 영웅이 됩니다.
- 몬스터: 해골병사(역병 희생자가 되살아나기도 함), 건물까지 부수는 거대한 트롤, 물면 감염시키는 좀비, 화염구·순간이동·사령술을 쓰는 마법사, 땅을 태우는 악마, 물을 얼리고 불을 끄는 냉기 정령, 생명체를 빔으로 납치하는 UFO(번개에 맞으면 추락하고 외계인이 기어 나옴), 마을을 불태우는 드래곤. 도서관에서 수련한 마을 마법사는 부상자를 치료하고, 산업 시대의 탑은 기관총 포탑이 됩니다.
- 원소 상호작용: 불은 숲으로 번지고 물·비·냉기에 꺼지며, 번개는 금속(전차·UFO)을 찾아 떨어지고, 산성비는 금속을 살보다 빨리 부식시키고 작물을 죽이며, 네이팜은 넓은 지역에 불을 붙이고, 불붙은 생명체는 물로 달려갑니다.
- 행동 AI(유틸리티 점수): 싸울지 도망칠지를 힘·용기·성격·종으로 판단, 불·용암·산성비·토네이도·낙하물 그림자 회피, 마을 방어 호출·무리 경보·늑대 무리 사냥, 배고픔·기력·부상에 따른 욕구 우선순위. 물에 빠지면 숨 게이지가 줄고 가까운 해안으로 헤엄치며, 고립된 섬에서는 본토로 건너갑니다. 멈춘 개체는 감시자(watchdog)가 자동으로 풀어 줍니다.
- 물리: 넉백은 관성으로 미끄러지다 멈추고 벽에 막히며, 던져진 생명체는 포물선을 그리며 떨어지고 높이 떨어질수록 크게 다칩니다. 몸은 나무 줄기·바위·건물과 겹치지 않습니다.
- 전쟁 지도: 전쟁 중인 왕국 색 영토, 원정군 진군 화살표, 전선, 목표 도시 표시. 정보 카드는 상태·직업·능력 아이콘(링 게이지)과 마우스를 올리면 이름·수치·설명이 뜨는 팝오버로 보여 줍니다.
- 생태계: 데이터로 정의된 먹이사슬(`src/sim/foodchain.ts`)대로 토끼·닭·양·사슴·물고기 → 여우·멧돼지 → 늑대·곰·사람 → 악어 → 드래곤이 사냥하고 도망칩니다. 계절, 비구름, 번지는 불, 무작위 재해(토네이도·운석·지진·역병·가뭄·홍수)와 화산.
- 욕구와 기분: 배고픔·기력·친교, 기억(슬픔·결혼·출산·약탈…), 연인·부모·친구·원수 관계가 행동과 노동 효율, 출생, 충성, 범죄로 이어집니다.
- 문명 발전: 지식이 쌓이면 부족 → 중세 → 화약 → 산업 → 현대로. 도서관·시장·감옥·부두·포대·공장·아파트, 경비병·상인·어부·학자·노동자, 머스킷·소총, 어선·전함·이주선, 전차·폭격기.
- 경제와 질서: 상인이 남는 자원을 이웃에 팔고 대금을 받아 오며(교역은 우호를 높이고 연구를 돕습니다), 부족한 왕국은 부유한 이웃에게 약탈 전쟁을 겁니다. 도둑·살인자·선동가는 경비병이 체포해 감옥으로 호송하고, 감옥은 반란을 진압할 수 있습니다.
- 세계 확장: 가장자리 밖에 땅을 칠하면 세계가 청크 단위로 넓어집니다(최대 768). 새 세계는 XL(384²)과 와이드(512×256)도 고를 수 있습니다.

## 구조

| 경로 | 역할 |
| --- | --- |
| `src/sim/` | 렌더링과 무관한 순수 시뮬레이션(세계 생성, 주민 AI, 마을·왕국, 자연, 재해, 신의 능력, 저장). 다른 엔진으로 옮기기 쉽도록 타입 배열과 평범한 객체만 사용 |
| `src/render/` | Three.js 렌더링: 2D↔3D 카메라 리그, 지형/물 셰이더, 인스턴싱된 식생·건물·생명체, 이펙트, 아이콘 포지, 후처리 |
| `src/render/models/` | 절차적 모델링 키트와 모든 3D 모델(종족별 건축, 생명체, 식물) |
| `src/physics/` | Rapier 물리(날아가는 주민, 던지기, 파편) |
| `src/audio/` | WebAudio로 합성하는 효과음·환경음·생성 음악 |
| `src/ui/` | Preact UI(타이틀, 세계 생성, HUD, 도구 막대, 패널, 지도 라벨) |
| `tools/simtest.ts` | 헤드리스 시뮬레이션 테스트: `npx tsx tools/simtest.ts <seed> <years> <tribes> <size>` |
| `tools/movetest.ts` | 이동 회귀: 건물 관통·제자리 걷기·원거리 벌목 0건 확인 |
| `tools/p3test.ts` | 부족→교역, 부족→전쟁(대조군 포함), 체포→수감→석방, 시대→시설/직업 |
| `tools/p4test.ts` | 관측된 사냥이 먹이사슬 표와 일치, 가뭄 연쇄(대조군 비교), 화산 회복, 핵 낙진 |
| `tools/perftest.ts` | 월드 크기·개체 수별 틱당 비용 |
| `tools/combattest.ts` | 포대·전함·폭격기·드래곤의 실제 피해, 홍수 침수·배수, 하늘에서 떨어지는 핵의 지연 |
| `tools/territorytest.ts` | 영토 위생: 죽은 마을 땅, 한 칸 고립 영토, 지그재그 경계, 남의 땅 위 건물 |
| `tools/stucktest.ts` | 장시간 멈춤·물속 갇힘 회귀(25초 이상 제자리인 개체, 감시자 구조 횟수): `npx tsx tools/stucktest.ts <seed> <years> [size]` |
| `tools/watertest.ts` | 물속 나무 없음, 먼바다 익사, 해안까지 헤엄, 고립 섬 탈출, 침수된 나무 고사 |
| `tools/cameratest.ts` | 줌 아웃/인 후 방향 유지, 프레임 간 방향 튐 없음, 커서 기준 줌, 이동 키 = 화면 위쪽 |
| `tools/aitest.ts` | 무리 경보, 무리 사냥, 도움 요청, 위험 회피, 성격·종 차이, 욕구 우선순위 |
| `tools/monstertest.ts` | 몬스터·원소 상호작용과 저장→불러오기 후 동일 재생 |
| `tools/physicstest.ts` | 넉백 관성, 벽 충돌, 중력·낙하 피해, 던지기 포물선, 줄기·바위 겹침 없음 |
| `tools/wartest.ts` | 전쟁 지도: 원정, 전선, 평화 후 정리 |
| `tools/tickprof.ts` | 틱 비용 분해와 백분위수(빨리 감기에서 느껴지는 끊김): `npx tsx tools/tickprof.ts [size] [years] [ticks]` |
| `tools/soak.ts` | 무인 장시간 실행 + 저장→불러오기 후 결정론 확인: `npx tsx tools/soak.ts <years> <size>` |

## 그래픽 품질

설정 → 소리 패널의 *그래픽* 토글로 후처리(SSAO·틸트시프트·블룸·색보정)를 끄고 켤 수 있습니다. 프레임이 계속 느리면 자동으로 가벼운 모드로 전환됩니다(URL에 `?noauto`를 붙이면 비활성).
